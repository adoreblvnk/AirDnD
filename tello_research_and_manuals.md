## 3. Communication Architecture & SDK Levels

All Tello drones communicate via plain text commands transmitted over **UDP** packets.

### Network Sockets & Ports
* **Command Port (Send to Drone)**: UDP `192.168.10.1:8889` (in AP mode) or `<assigned_ip>:8889` (in Station mode).
* **State / Telemetry Port (Listen from Drone)**: UDP `0.0.0.0:8890`. State strings broadcast at ~10 Hz (e.g., `pitch:0;roll:0;yaw:0;vgx:0;vgy:0;vgz:0;templ:55;temph:58;tof:10;h:0;bat:90;baro:120.00;time:0;agx:0.00;agy:0.00;agz:-1000.00;`).
* **Video Stream Port (Listen from Drone)**: UDP `0.0.0.0:11111`. Transmits raw H.264 video frames once `streamon` is initiated.

## 4. Key Capabilities Breakdown

### 1. Programmability & Ecosystem
* **Python**: Fully accessible via raw UDP sockets, or high-level libraries like `djitellopy` and `easytello`.
* **ROS / ROS 2**: Accessible via `tello_ros` wrappers, bridging camera streams to ROS image transport and velocity commands to `cmd_vel`.
* **Scratch 3.0 / Mind+ / DroneBlocks**: Block-based visual programming for educational curriculum and rapid prototyping.
* **Swift Playgrounds**: Native iOS support for interactive coding modules.

### 2. Vision & Sensor Integration (Tello EDU)
* **Mission Pads**: 8 unique dual-sided ID cards. The downward camera reads ID tags and computes relative offset vectors `(x, y, z)` in centimeters relative to the pad center, preventing dead-reckoning drift during long-distance indoor trajectories.
* **Computer Vision Pipeline**: The 720p H.264 stream can be piped into OpenCV / PyAV / Mediapipe for real-time edge processing (object detection, facial tracking, ArUco marker tracking, gesture control) running on the host machine.

### 3. Swarming (Tello EDU Exclusive)
* Tello EDU can connect as a client (Station Mode) to an external 2.4GHz / 5GHz Wi-Fi router.
* A central host computer on the same subnet can manage individual UDP sockets across multiple IP addresses to execute synchronized swarm choreography or coordinated search patterns.

## 5. Critical Technical Limitations

### 1. Navigation & Localization Limitations
* **No Onboard GPS**: Indoor-only stabilization based strictly on downward Optical Flow (VPS) and infrared ToF sensors.
* **VPS Surface Dependency**: Fails or drifts severely over:
  * Monochromatic or featureless surfaces (pure white floors, smooth single-color tiles).
  * Highly reflective surfaces (mirrors, polished marble, water).
  * Dark or poorly lit environments (< 100 lux).
  * Repetitive grid patterns.
* **Outdoor Environmental Vulnerability**: Very low wind resistance (< 3 m/s). Optical flow can easily miscalculate velocity over moving grass or outdoor shadows.

### 2. Network & Communication Bottlenecks
* **Standard Tello AP Mode Restriction**: Standard Tello cannot join an existing Wi-Fi network. Swarming multiple standard Tellos requires a host PC with multiple physical Wi-Fi dongles (one dedicated Wi-Fi interface per drone).
* **2.4 GHz Band Congestion**: In environments with dense Wi-Fi activity (classrooms, auditoriums, hackathons), UDP command loss and video stream frame dropping can occur.
* **UDP Connectionless Protocol**: Commands can be dropped without an automatic retransmission layer. Applications must implement ACK timeouts and retry mechanisms.

### 3. Hardware & Thermal Constraints
* **Brushed Motors**: Coreless brushed motors have finite operating lifespans (~50–100 flight hours) and generate significant heat.
* **No Active Fan Cooling**: Relies on prop-wash for cooling. When idling stationary on a flat surface, the drone will execute a thermal emergency shutdown within **2 to 3 minutes** to prevent damage to the Intel VPU.
* **Real-World Flight Endurance**: While rated for 13 minutes hover, continuous Wi-Fi video decoding and aggressive SDK command execution reduce practical battery life to **7 to 9 minutes per battery**.

### 4. Video & Storage Constraints
* **No Onboard MicroSD / Flash Storage**: No video or photo data is recorded directly onto the drone. All media must be streamed via Wi-Fi and written locally to the host controller storage.
* **Fixed Sensor / No Gimbal**: The camera is fixed to the forward chassis; attitude changes (pitch and roll) directly tilt the camera frame.
