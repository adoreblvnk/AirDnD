# AirDnD Frontend Design

## World

The worldview is an optical picket plotting table: a charcoal maritime field, chalk-white measurement text, blue friendly tracks, red hostile truth, amber uncertainty, and hairline geometry. It rejects dashboard cards, decorative tactical chrome, gradients, and redundant status badges.

## Composition

Cesium owns the center. A 184px command rail controls scope, perspective, and fixed replay. A 286px decision trace progressively discloses local reasoning. Timeline controls sit on the map edge; one uninterrupted blackout strip closes the viewport. Evidence is a separate ledger-like route.

## Typography

Barlow Condensed carries compact labels, actions, coordinates, and tabular measurement. Barlow carries explanatory copy. Labels use uppercase sparingly for operational controls. Numeric output uses tabular figures.

## Color

- Maritime field: `#081014`
- Ellipsoid plotting plane: `#102126`
- Chalk: `#dce7e5`
- Friendly / active control: `#58a8d8`
- Hostile evaluator truth: `#ed665b`
- Unknown / caution: `#e2b75d`
- Hairline: `rgba(180, 210, 208, .20)`

## Interaction

Flat buttons, one-pixel rules, and visible keyboard focus. Local perspectives automatically mask truth; truth returns only through the explicit evaluator control. Decision detail and three-unit comparison open in place. Playback is authoritative by integer frame and supports Space, arrows, and `T`.

## Cesium Discipline

Resium owns only the stable Viewer shell. Cesium `CustomDataSource` registries separately own local, evaluator-truth, and procedural ellipsoid geometry. Entity coordinates update imperatively by frame. Camera changes have one owner. Paused playback uses request-render mode. Labels are limited to selected and interpreted tracks.

## Responsive Behavior

At narrow desktop widths, the decision trace moves below the field. On mobile, the rail becomes a shallow command header, the map remains primary, and secondary unit selection yields to the selected decision.
